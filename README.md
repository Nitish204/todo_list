# ✨ Aurora Task Manager

A modern, feature-rich desktop Task Management application built using Python and Tkinter.

Aurora Task Manager provides a beautiful UI, task prioritization, filtering, search, due dates, categories, and persistent storage — all inside a lightweight desktop application.

---

## 🚀 Features

### Task Management
- Create tasks
- Edit tasks
- Delete tasks
- Mark tasks as completed
- Clear completed tasks

### Priority Levels
- 🔴 High
- 🟠 Medium
- 🟢 Low

### Categories
- Work
- Personal
- Health
- Learning
- Finance
- Other

### Search & Filters
- Search tasks instantly
- Filter by status
- Filter by category
- Filter by priority

### Productivity Dashboard
- Total Tasks
- Completed Tasks
- Pending Tasks
- High Priority Tasks

### Persistent Storage
Tasks are automatically saved locally using JSON.

### Modern UI
- Dark theme
- Premium design
- Custom widgets
- Toast notifications
- Responsive layout

---

## 🛠 Tech Stack

- Python 3.8+
- Tkinter
- ttk
- JSON Storage
- Object-Oriented Programming
